# Тестовый репозиторий: пакеты названы большими латинскими буквами.
# Формат строки: ИМЯ: зависимости через пробел

# Случай 1. Ромб: у D два родителя, повторов в графе нет.
A: B C
B: D
C: D
D:

# Случай 2. Цикл: E -> F -> G -> E, у G есть ещё зависимость H.
E: F
F: G
G: E H
H:

# Случай 3. Пакет зависит сам от себя.
I: I J
J:

# Случай 4. Фильтр по подстроке: имена с буквой B исключаются.
K: KB BK L
KB: L
BK: L
L:

# Случай 5. Зависимость N не описана в репозитории.
M: N Z
Z:

# Случай 6. Пакет без зависимостей.
Y:
