# depgraph

Инструмент визуализации графа зависимостей пакетов Alpine Linux (apk).
Практическая работа, вариант 8.

## 1. Общее описание

`depgraph` - консольное приложение на Python 3, которое анализирует
зависимости пакета менеджера Alpine Linux без использования готовых
менеджеров пакетов и библиотек для получения зависимостей.

Реализован **этап 1** - минимальный прототип с конфигурацией: приложение
читает настройки из YAML-файла, проверяет их и выводит в формате
`ключ: значение`. Последующие этапы (сбор данных, граф зависимостей,
обратные зависимости, визуализация в Mermaid) будут добавлены отдельными
коммитами.

Структура репозитория:

```
src/depgraph/   исходный код (config.py, cli.py, errors.py)
tests/          модульные тесты (unittest)
examples/       примеры конфигураций и тестового репозитория
Makefile        сборка, запуск и тесты
```

## 2. Описание функций и настроек

### Настройки (YAML-файл)

Все шесть параметров обязательны; неизвестные ключи запрещены.

| Ключ               | Тип    | Описание                                                    |
|--------------------|--------|-------------------------------------------------------------|
| `package_name`     | строка | Имя анализируемого пакета: латинские буквы, цифры, `. _ + -`; начинается с буквы или цифры |
| `repository`       | строка | URL репозитория (`http`/`https`) или путь к файлу тестового репозитория |
| `test_mode`        | bool   | `true` - `repository` это путь к существующему файлу; `false` - это URL |
| `package_version`  | строка | Версия в формате Alpine: `1.2.3`, `1.2.3-r0`, `2.0_rc1`. Берите в кавычки (`"1.10"`), иначе YAML превратит её в число |
| `ascii_tree`       | bool   | Режим вывода зависимостей в виде ASCII-дерева               |
| `filter_substring` | строка | Подстрока для фильтрации пакетов; может быть пустой `""`, без пробелов |

Пример: `examples/config.yaml`.

### Командная строка

```
python -m depgraph [-c PATH]
```

| Опция              | Описание                                          |
|--------------------|---------------------------------------------------|
| `-c`, `--config`   | путь к YAML-файлу (по умолчанию `config.yaml`)    |
| `-h`, `--help`     | справка                                           |

Коды завершения: `0` - успех, `2` - ошибка конфигурации или аргументов.

### Модули и функции

- `config.py`: `load_config(path)` - загрузка и проверка; `validate(raw)` -
  проверка словаря; `check_*` - проверки отдельных параметров; класс
  `Config` с методом `as_pairs()`.
- `cli.py`: `main(argv)` - точка входа; `print_params` - вывод
  `ключ: значение`; `report_errors` - вывод ошибок в stderr.
- `errors.py`: `ConfigError` - исключение со списком всех проблем.

### Обработка ошибок

Обрабатываются: отсутствующий файл, директория вместо файла, ошибка
чтения, не-UTF-8, некорректный YAML, пустой файл, корень не словарь,
неизвестные и отсутствующие ключи, неверный тип или формат каждого
параметра, неверный URL, несуществующий файл тестового репозитория.
Все найденные проблемы выводятся сразу.

## 3. Сборка и тесты

Требуется Python 3.9+.

```
make install   # pip install -r requirements.txt (PyYAML)
make run       # запуск с examples/config.yaml
make test      # запуск тестов
```

Без make:

```
pip install -r requirements.txt
PYTHONPATH=src python3 -m depgraph -c examples/config.yaml
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 4. Примеры использования

Корректная конфигурация (`make run`):

```
$ python -m depgraph -c examples/config.yaml
package_name: busybox
repository: https://dl-cdn.alpinelinux.org/alpine/v3.20/main
test_mode: false
package_version: 1.36.1-r29
ascii_tree: true
filter_substring: musl
```

Тестовый режим (`make run CONFIG=examples/config_test_mode.yaml`):

```
$ python -m depgraph -c examples/config_test_mode.yaml
package_name: A
repository: examples/test_repo.txt
test_mode: true
package_version: 1.0
ascii_tree: false
filter_substring: ""
```

Ошибки в параметрах (код завершения 2):

```
$ python -m depgraph -c bad.yaml
Ошибка конфигурации:
  - параметр 'package_name': недопустимое имя '-bad name'; ...
  - параметр 'test_mode' должен быть логическим (true/false), получено: 'yes'
  - параметр 'package_version' должен быть строкой, получено: 1.1 (возьмите значение в кавычки)
  - параметр 'ascii_tree' должен быть логическим (true/false), получено: 5
  - параметр 'filter_substring' не должен содержать пробельных символов
```

Тестовый режим с несуществующим файлом:

```
  - параметр 'repository': файл не найден: /no/such/file.txt
```

Несуществующий файл конфигурации:

```
$ python -m depgraph -c nope.yaml
Ошибка конфигурации:
  - файл конфигурации не найден: nope.yaml
```
